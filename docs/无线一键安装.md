# 免传 APK：无线一键安装到手机

适用场景：**电脑连的是手机热点、没有 Wi‑Fi 路由器** —— 也完全可用，因为电脑和手机在同一个局域网里。

> 前提：Android 11 及以上（自带「无线调试」配对功能）。若手机是 Android 10 及以下，需要先用数据线执行一次 `adb tcpip 5555`。

## 一次性：配对手机

1. 手机开启开发者选项：设置 → 关于手机 → 连续点「版本号」7 次。
2. 设置 → 系统 → 开发者选项 → 打开 **无线调试**。
3. 点进「无线调试」→ **使用配对码配对设备**，屏幕会显示：
   - `IP 地址和端口`（例如 `192.168.43.1:41234`）← **配对用**
   - 一个 6 位配对码
4. 电脑双击 `tools\pair-wireless.bat`，按提示输入上面的 IP:端口 和配对码。

## 以后每次更新：双击 `tools\deploy-debug.bat`

它会自动：
1. 编译 Debug APK；
2. 找到已连接手机（没有就提示你输入「无线调试」主页面显示的 `IP:端口` 并连接）；
3. 覆盖安装；
4. 启动 App。

## 关于「手机热点」的 IP

- 电脑连手机热点时，手机通常就是网关。用 `cmd` 运行 `ipconfig`，在无线网卡那段看「默认网关」，那就是手机 IP（如 `192.168.43.1`）。
- 「无线调试」主页面显示的 IP 若不是 `192.168.x.x`（比如显示了流量卡的地址），就改用 `ipconfig` 里的默认网关作为 IP，端口仍用屏幕上显示的那个。
- 端口在每次关闭/重开「无线调试」或重启手机后会变，所以 `deploy-debug.bat` 允许你每次输入最新端口。

## 常见问题

| 现象 | 处理 |
|---|---|
| `adb pair` 报错 | 配对码有效期很短，重新点「使用配对码配对设备」再输入；确认同一网络 |
| `adb connect` 连不上 | 端口填成配对端口了；改用「无线调试」主页面的端口；或重启一次无线调试 |
| 提示 unauthorized | 手机上出现「允许 USB 调试吗？」时点允许 |
| 找不到 adb | 脚本已内置 `D:\Android\Sdk\platform-tools\adb.exe`；若你的 SDK 在别处，改脚本首部 `ADB=` 即可 |
| 手机重启后连不上 | 重新打开无线调试，运行 `deploy-debug.bat` 输入新端口 |

> 安全提示：无线调试用完可在手机上关掉；它只在你当前的局域网内可见。
